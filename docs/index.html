Guide

How to use AI Music Studio

1. Create a track

Use + Track to add an instrument or sample track. Right-click a track to assign a bundled or third-party rack instrument.

2. Draw in the piano roll

Choose the pencil tool, draw notes, and click existing notes to select, move, or resize them. Mouse wheel zoom works across editor views.

3. Pick a sound

Set Instrument type to VSTI Rack, choose a supported VST3, then open the bundled editor or wrapper to shape the patch live.

4. Loop and play

Use the left and right locators to define the loop range, then hit Play. Synth playback stays realtime instead of going through temp WAV files.

5. Shape the mix

Open the Mixer tab to adjust volume, pan, mute, solo, and insert VST FX. Track colors carry across the arranger and editors.

6. Render or export

Export MIDI, render audio stems, or package the app using the release process below.

Release

Build and publish

Local Windows package

powershell -ExecutionPolicy Bypass -File .\scripts\build_windows_release.ps1 -ReleaseVersion v0.1.0

The script installs build dependencies, packages the desktop app with PyInstaller, and creates a portable ZIP containing AI Music Studio.exe.

GitHub release automation

git tag v0.1.0
git push origin main --tags

Pushing a v* tag triggers the release workflow, which rebuilds the bundled VST3 instruments, packages the Windows app, and publishes the ZIP plus SHA256 checksum to GitHub Releases.

Notes

Compatibility

Supported plugins

The shipping host path targets VST3. Unsupported plugins are filtered out of the rack UI so the playable list stays clean.

Audio control

The new Audio Settings window keeps output selection, buffer length, sample format, and native VST host startup settings together in one place.

Bundled instruments

The portable build includes bundled AI Bass Synth, AI Drum Machine, and AI String Synth VST3 instruments with themed in-app editors.
