Mutagen AI Music Studio

Mutagen is a native C++ music production app for MIDI-first workflows. It combines a desktop sequencer, piano roll editor, live VST3 hosting, bundled synths and instruments, sample tools, automation, and AI-assisted composition in a standalone Windows-ready workstation.

  • Desktop AI music studio workflow with sequencer, piano roll, controller lanes, mixer, and arrangement tools.
  • Live VST3 engine with shared playback and editor state, so sound design changes hit the running session immediately.
  • Current supported path is the native app. The deprecated Python shell is no longer part of the shipping workflow.
Why people use Mutagen
  1. Sketch MIDI ideas fast with a pattern sequencer and piano roll.
  2. Open bundled or third-party VST3 instruments in a live desktop workflow.
  3. Use AI composition tools, automation, samples, and floating editors in one app.
  4. Download Windows releases or build from source with JUCE-based native tooling.

Help

Core Mutagen workflow

1. Add or select a track

Create an instrument or sample track, then load a bundled or third-party VST3 plugin when you need a synth, sampler, or drum source.

2. Draw pattern clips

Use the desktop sequencer to draw pattern blocks at the current pattern size, then open them directly in the piano roll for note editing.

3. Edit notes and controllers

Use the piano roll for notes and the lower pane for velocity, MIDI CC, and automation-style controller editing inside the same music workflow.

4. Open the live VST

Use Edit VST or the track V toggle to open the live plugin editor. Parameter moves apply straight to the running engine.

5. Mix and arrange

Use the mixer, locator handles, pattern tools, and floating windows to arrange the song structure and balance the session.

6. Export and inspect logs

Export stems or track renders, then inspect the activity log and AI HTTP debug log when diagnosing AI-assisted composition output.

Flagship Instrument

Virus Synth manual

Virus Synth is the most detailed bundled instrument in the rack. It includes shared oscillator controls, modulation and matrix pages, dual filters, FX pages, a shift layer, and preset browsing through the LCD and OSD workflow.

  • LCD-based preset browsing and page navigation
  • Shared oscillator editing with per-oscillator focus
  • Filter, FX, LFO, and matrix pages through the value controls
  • Preview keyboard and background toggle inside the editor

Release

Build and publish

Local Windows package

powershell -ExecutionPolicy Bypass -File .\scripts\build_windows_release.ps1 -ReleaseVersion v0.3.2

The packaging script builds the native app, copies the bundled VST3 instruments, and creates a portable ZIP containing Mutagen.exe.

GitHub release automation

git tag v0.3.2
git push origin main --tags

Pushing a v* tag triggers the native Windows release workflow and publishes the ZIP, installer, and SHA256 checksums to GitHub Releases.
